# Phase 2 - Customizer 全量迁移与分层重构

目标：把 `Shinonomeiro Options` 的设置能力逐步收敛到 `主题 -> 自定义`，并重整结构分层，保持兼容、可回滚。

## 里程碑

### M1（已开始）- 盘点与映射基线
- [x] 建立 phase2 分支：`feat/customizer-phase2-foundation`
- [ ] 导出现有 CSF section/field 清单
- [ ] 建立 `旧键 -> Customizer setting_id` 映射表（含默认值、sanitize）

### M2 - 分层骨架
在 Customizer 增加统一面板（仅骨架，不改功能逻辑）：
- 全局与品牌
- 外观与主题色
- 首页开屏与动画
- 页头导航
- 文章与页面
- 评论与互动
- 媒体与资源/CDN
- 性能与缓存
- 高级与开发者

### M3 - 第一批字段迁移（高频）
优先迁移高频且低风险项：
- Logo/标题/主题色/深色模式
- 首页开屏相关（含 hide splash）
- 导航搜索/用户菜单

### M4 - 第二批字段迁移（功能类）
- 评论、表情、邮件通知
- SEO、统计、社交
- 图片/CDN/字体

### M5 - 清理与收口
- 移除旧菜单依赖（保留兼容读取）
- 清理重复字段和历史文案
- 完整回归测试与发布

## 兼容与回滚策略
- 单向迁移：旧配置仍可读，新保存写入统一存储。
- 保留回滚常量：`SHINONOMEIRO_ENABLE_LEGACY_OPTIONS_MENU`。
- 每个里程碑单独 PR，出现问题可回退到上一个版本。

## 验收标准
- 用户只通过 `主题 -> 自定义` 即可完成全部设置。
- 不出现配置丢失。
- 前台行为与旧版本一致（除明确优化项）。
