> 一款具有 AI 辅助阅读功能的 WordPress 主题，多彩、友好、功能全面、体验完善。

## 项目介绍

Shinonomeiro 是一个基于 Sakura V3 系列重构开发的 WordPress 主题，提供：

- 可视化主题配置
- 丰富的首页与文章展示样式
- 多种导航与交互体验增强
- 主题级功能扩展能力

开源协议：GPL-2.0

## Fork 说明

本仓库是 `LHabc-me/Shinonomeiro` 的个人维护版本，用于：

- 记录本仓库独立发布版本

如需查看上游项目：

- 当前仓库：https://github.com/LHabc-me/Shinonomeiro
- 上游文档：https://docs.fuukei.org/

## 使用与发布

- 本仓库 Release：https://github.com/LHabc-me/Shinonomeiro/releases
- 当前版本基线：v1.2.1
- 从 v1.1.0 起默认收敛到「主题 -> 自定义」；若需临时恢复旧 `Shinonomeiro Options` 菜单，可在 `wp-config.php` 中设置：`define('SHINONOMEIRO_ENABLE_LEGACY_OPTIONS_MENU', true);`
- 建议通过 Release 页面下载对应版本并部署
